# Персональный финансовый помощник на основе NLP

Система подбора кредитных продуктов для физических лиц по свободному текстовому запросу.
Понимает цель пользователя на русском и казахском языках, находит подходящие кредиты
по смыслу, объясняет выбор и рассчитывает платёж.

## Возможности

- Семантический поиск по смыслу запроса (гибрид: эмбеддинги MiniLM + BM25 + переранжирование)
- Извлечение параметров из текста (категория, сумма, срок) на основе правил
- Двуязычность: ответ на языке запроса (русский / казахский)
- Объяснимые рекомендации, расчёт аннуитетного платежа с графиком
- Админ-панель, аналитика, обратная связь

## Данные

44 кредитных продукта, 14 банков Казахстана, 6 категорий: потребительский кредит,
рефинансирование, ипотека (включая госпрограммы), автокредит, микрокредит, целевой.

## Запуск

```
pip install -r requirements.txt
python import_catalog.py      # каталог в базу + эмбеддинги (один раз)
streamlit run app.py
```

Приложение откроется на http://localhost:8501. Админ-панель — пароль в боковой панели.

## Эксперименты

```
python eval.py                # сравнение методов поиска
python eval_multilang.py      # мультиязычность (русский / казахский)
```

## Стек

Python, Streamlit, SQLite, sentence-transformers (paraphrase-multilingual-MiniLM-L12-v2),
rank-bm25, scikit-learn.
